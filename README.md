# Литература и котики — учебная мини-платформа

Готовый статический сайт для GitHub Pages. Откройте `index.html` или опубликуйте содержимое папки в корне репозитория.

## Публикация
1. Создайте публичный репозиторий GitHub, загрузите **все файлы и папки** (index.html, materials, img).
2. Откройте Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
3. Дождитесь адреса страницы.

Видеоплееры загружаются с Kinescope, поэтому им нужен интернет и разрешение на встраивание от владельца роликов. PDF раздаются непосредственно через GitHub Pages. Тесты работают в браузере без сервера, баллы никому автоматически не отправляются.

**Палитра:** теплый кремовый, желтый, розовый, бордовый. Изображение с точными HEX-кодами не было доступно среди файлов запроса, поэтому использованы цвета, подобранные по предоставленным конспектам.
